Messenger link test (iPhone)

For the Moodeng team only. Use an iPhone, and open this page by tapping its link inside Messenger, the same way a borrower opens moodeng.app.

How to test (3 minutes):
  1. Check the line under "Results" says In-app browser: yes. If it says no, you opened it in Safari: go back to Messenger and tap the link there.
  2. Tap a button. Watch what the phone does. If the Moodeng Credit chat opens, wait ~5 seconds to see if the bot replies.
  3. Come back to this page (the "◀ Messenger" in the top-left corner, or reopen the link). If this page changed to another page, tap Back or reopen the link.
  4. Answer "What happened?" under that button, then do the next one.

Some links carry a fake code. A bot reply saying the code didn't work is a success here: it means the code reached the bot. Nobody gets confirmed.
