Messenger link test

For the Moodeng team only. Use an Android phone in Chrome, logged in to Facebook/Messenger like a normal borrower.

How to test (2 minutes):
  1. Tap a button. Round 2: just try G to K.
  2. Watch what the phone does. If Messenger opens on the Moodeng Credit chat, wait ~5 seconds to see if the bot replies.
  3. Come back to this Chrome tab (Back button or app switcher). If the tab changed to another page, press Back.
  4. Answer "What happened?" under that button, then do the next one.

The A–D and G–K links carry a fake code. A bot reply saying the code or link didn't work is a success here: it means the code reached the bot. Nobody gets confirmed.
