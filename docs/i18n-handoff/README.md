## How translation works in this app

There are three layers.

1. **Keyed strings** live in `src/i18n/translations.ts`, one object per locale, and are read with `t('key')`.
2. **Phrase maps** in `src/i18n/screenTranslations.ts` map an exact English UI string to its translation. `src/i18n/LocalizationDomBridge.tsx` and `phraseTranslation.ts` walk the rendered DOM: text nodes plus the `aria-label`, `title`, `alt` and `placeholder` attributes. They collapse whitespace and look each text up by **exact match**.
   - Changing an English string, even its capitalization or a curly vs straight apostrophe, silently breaks its translation.
   - Text split by `{variables}` or by tags like `<strong>` and `<br/>` renders as separate text nodes, so each fragment needs its own key.
3. **Coverage maps** in `src/i18n/coverage/<locale>{A,B,C}.ts` are new in this PR. They hold the same exact-English → translation mapping for screens that had none.
   - Each locale's three files are merged in `coverage/<locale>.ts` and **lazy-loaded** by `coverage/index.ts`, only when a visitor picks that language. Each language is a separate 60–275 KB chunk.
   - Where both define a string, `screenTranslations.ts` wins over the coverage maps.
   - Strings from inline `{ en, fil }` objects that lack a locale render in English, and the coverage maps then translate them too.

Some components also have inline per-locale objects (`COPY[locale]`). The long-form content is locale-switched data:

- `src/views/support/data/guides.ts`
- `src/views/support/data/faqs.ts`
- `src/views/account/data/accountFaqs.ts`
- `src/views/help/helpTopics.ts`, which has only `en`/`fil`; other locales go through the coverage maps.

## Tips that save time and usage

- **Don't run many agents at once.** 13 parallel agents hit the usage limit within about two hours, three times over. Use one or two at a time, or a cheaper model for the bulk coverage work.
- **Commit after every file or batch.** Cutoffs lost work and once left a half-written line. It happened in `thC.ts` and was fixed.
- **Check that each file holds only its own language.** After a cutoff, about 40 Indonesian values were found in the Thai file and removed. A quick script check: Thai values must contain Thai script, and Vietnamese values must contain Vietnamese diacritics.
- **Rules for every translator:** read `glossary/common.md`, which has the product facts and the list of terms to keep in English, and `glossary/<locale>.md`.
