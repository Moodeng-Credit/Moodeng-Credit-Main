# Thai (th) glossary
Register: polite, neutral app Thai. Address the user as คุณ. Do not use ครับ/ค่ะ in UI, and do not use informal มัน for things. Use Thai spacing conventions: no English commas in Thai lists, and no stray spaces before words.

| English | Thai |
|---|---|
| borrower / lender | ผู้ยืม / ผู้ให้กู้ |
| loan | เงินกู้ |
| Request Board | กระดานคำขอ |
| Dashboard | แดชบอร์ด |
| wallet | กระเป๋าเงิน (keep product names "Instant Wallet" and "Base Account") |
| Credit Level | ระดับเครดิต ("Level 1" = ระดับ 1) |
| credit limit | วงเงิน / วงเงินกู้ |
| Pandesal points | แต้ม Pandesal (no space before แต้ม at a phrase start) |
| IOU points | แต้ม IOU |
| repay / repayment | ชำระคืน / การชำระคืน ; Pay now = ชำระเลย ; Repaid = ชำระคืนแล้ว ; Paid = ชำระแล้ว |
| fund (lender action) / funded | ปล่อยกู้ / ปล่อยกู้แล้ว |
| Active (loan) | กำลังดำเนินอยู่ |
| Outstanding | ยอดคงเหลือที่ต้องชำระ |
| Overdue / Defaulted | เกินกำหนด / ผิดนัดชำระ |
| Pending | รอดำเนินการ |
| Failed | ไม่สำเร็จ |
| reputation | ความน่าเชื่อถือ (NEVER ชื่อเสียง) |
| Milestones | หมุดหมาย |
| Guest | ผู้เยี่ยมชม |
| Help / Support | ช่วยเหลือ / ฝ่ายช่วยเหลือ |
| Sign up | สมัครสมาชิก |
| setup fee / network fee | ค่าธรรมเนียมแรกเข้า / ค่าธรรมเนียมเครือข่าย (ค่า gas) |
| exchange (crypto) | แพลตฟอร์มแลกเปลี่ยนคริปโต |
| onchain | ออนเชน |
| Microloan | สินเชื่อรายย่อย |
| Academy | อะคาเดมี |
| Verify Yourself / Verify Your ID / Verify with World ID | ยืนยันตัวตน / ยืนยันด้วยบัตรประชาชน / ยืนยันด้วย World ID |
| Withdraw / Add funds / Cash out | ถอนเงิน / เติมเงิน / ถอนเป็นเงินสด |
| What's next? | ขั้นตอนต่อไป |
