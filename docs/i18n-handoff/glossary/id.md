# Indonesian (id) glossary
Register: friendly, informal "kamu" everywhere (never "Anda"), like Indonesian fintech apps (Jenius, GoPay). Use natural Indonesian, and avoid English words that have a common Indonesian equivalent.

| English | Indonesian |
|---|---|
| borrower / lender | peminjam / pemberi pinjaman |
| loan | pinjaman |
| loan request | permintaan pinjaman ("application" = pengajuan pinjaman) |
| Request Board | Papan Permintaan |
| Dashboard | Dasbor |
| Home | Beranda |
| wallet | dompet (keep product names "Instant Wallet" and "Base Account") |
| Credit Level | Level Kredit (capital L and K; "level kredit" mid-sentence is also fine) |
| credit limit | limit kredit |
| Pandesal points | poin Pandesal ("Poin Pandesal" at label start) |
| IOU points | poin IOU |
| repay / repayment | bayar kembali (button "Bayar") / pembayaran kembali |
| due date | jatuh tempo |
| interest rate | suku bunga (NOT "rate bunga") |
| pending | menunggu |
| funded | didanai; fund (lender action) = mendanai |
| overdue / default | terlambat / gagal bayar |
| role | peran |
| verify / verified | verifikasi / terverifikasi |
| Verify Yourself / Verify Your ID / Verify with World ID | Verifikasi Diri / Verifikasi ID Kamu / Verifikasi dengan World ID |
| Guest User | Pengguna Tamu |
| short-term support / funds | dana jangka pendek |
| Milestones | Pencapaian |
| Rewards | Hadiah |
| Withdraw / Add funds / Cash out | Tarik dana / Tambah dana / Cairkan dana |
