# Filipino (fil) glossary
Register: casual, natural Taglish as Filipino fintech apps write it. Use "mo/ka/ikaw", not "po/ninyo". Use i-tap / i-verify / mag-apply style verbs. Avoid stiff formal Tagalog ("kredito", "Beripikado", "Kasaysayan", "Humihiram" as a noun).
