# Shared rules (all languages)

Product facts (the English source is the truth; these are the current facts):
- Verification: the recommended path is "Verify Your ID": an ID photo plus a selfie, about 3 minutes. A human review, if needed, takes at most 1 business day. The ID is checked by a partner and never stored by Moodeng. The alternative is "Verify with World ID" for existing World App users. There is NO Worldcoin reward. Visiting an Orb is NOT required.
- Credit limit progression: $15 → $20 → $40 → $60 → $80 → $100 → $120 → $140. $140 is the current MAXIMUM; never say "and beyond" or "and up".
- Only a Credit-Building Loan (a loan for your FULL current limit, repaid in full and on time) raises your Credit Level. A Trust-Building Loan is below your limit: it builds repayment history and Pandesal points but does not raise the level. Every on-time repayment earns Pandesal points.
- Pandesal points = the borrower points and reputation system (formerly "Trust Score" / "Trust Points", which are stale words). IOU points / IOU tokens = the lender reward system (NOT stale).
- USDC must always be sent on the Base network. The wrong network can lose the funds.
- A Base Account is seedless. Moodeng never asks for a seed or recovery phrase.
- GrabFood vouchers (₱50 / ₱100) are milestone rewards.
