# Vietnamese (vi) glossary
Register: friendly and polite, addressing the user as "bạn", like Vietnamese fintech apps (MoMo, ZaloPay). Use natural Vietnamese. Avoid calques ("chạm vào tiền", "ăn vào") and English left in the text.

| English | Vietnamese |
|---|---|
| borrower / lender | người vay / người cho vay |
| loan | khoản vay |
| Request Board | Bảng yêu cầu |
| Dashboard | Tổng quan |
| wallet | ví (keep product names "Instant Wallet" and "Base Account") |
| Credit Level | Hạng tín dụng ("Level 1" = Hạng 1) |
| credit limit | hạn mức tín dụng / hạn mức |
| Pandesal points | điểm Pandesal ("Điểm Pandesal" at label start) |
| IOU points | điểm IOU |
| repay / repayment | trả nợ / khoản trả nợ ; Repayments = Trả nợ ; Pay now = Trả ngay |
| fund (lender action) / funded | cấp vốn / đã được cấp vốn |
| Full (amount) | Toàn bộ |
| Pending | Đang chờ |
| Overdue / Defaulted | Quá hạn / Vỡ nợ |
| Milestones | Cột mốc |
| Academy | Học viện |
| settle (a transfer) | hoàn tất |
| Microloan | khoản vay nhỏ / vi mô |
| Verify Yourself / Verify Your ID / Verify with World ID | Xác minh danh tính / Xác minh bằng giấy tờ tùy thân / Xác minh bằng World ID |
| Withdraw / Add funds / Cash out | Rút tiền / Nạp tiền / Rút ra tiền mặt |
